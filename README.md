 📖 About

**SameFor** is a native Android app that leverages Firebase's powerful backend services to deliver seamless, real-time functionality to users. Built with modern Android development practices using Kotlin and Gradle Kotlin DSL.

 🚀 Features
 

- 🔥 Firebase integration (Authentication, Firestore, or Realtime Database)
- 📱 Native Android experience
- ⚡ Real-time data synchronization
- 🔒 Secure backend powered by Google Firebase
